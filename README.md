# RUNAWAY / ランナウェイ

街が、ゲームフィールドになる。ブラウザのGPSを使って遊ぶ、1人用の逃走ゲームです。

**公開版:** https://yuki1205.github.io/---100--/

## 遊び方

1. iPhoneまたはAndroidで公開URLを開く
2. 「1人で遊ぶ」から難易度と目標を選ぶ
3. 安全確認後、位置情報を許可する
4. GPS取得後に「逃走を開始」を押す
5. チェイサーから逃げ、時間または距離の目標を達成する

カウントダウンと逃走猶予のあと、チェイサーが追跡を始めた時点からミッションの時間計測が始まります。

## 現在の機能

- EASY / NORMAL / HARD とカスタム難易度
- 時間・距離の目標
- 最大5体のチェイサー、速度アップ、接近ダッシュ
- 接近時のブザー、対応端末でのバイブ、画面の赤色警報
- 結果共有、端末内への逃走記録保存、再挑戦
- PWA対応: ホーム画面に追加してアプリのように起動可能

## 安全とデータ

- 走行中は画面を見ず、周囲と交通ルールを最優先してください。
- 私有地や立入禁止区域には入らないでください。
- 位置情報はゲーム内の計測と地図表示に使います。RUNAWAYのサーバーには保存・送信しません。
- スコアと逃走記録は端末のブラウザ内に保存され、アプリ内から消去できます。
