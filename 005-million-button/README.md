# 100万円ボタン / #005

「100万円もらえる。ただし、条件がある。」に押す／押さないで答えるスマホ向け二択ゲーム。実際のお金の授受はありません。

## 起動

`index.html` をブラウザで開くと遊べます。静的ホスティングにもそのまま配置できます。公開・デプロイは未実施です。

## 初版の機能

- オリジナル30問から重複なしで10問を出題
- ランダム出題／端末の現地日付を使う「今日の10問」
- 押すたびに仮想の100万円を加算、10問終了後に称号を表示
- 全回答の振り返り、結果共有とコピーへのフォールバック
- 前回の結果だけ端末内に保存。保存できない環境でもプレイ可能
- スマホ・PC、キーボード操作に対応

HTML / CSS / JavaScriptのみ。外部ライブラリ、APIキー、サーバーは不要です。称号は押した回数による演出で、心理検査ではありません。オンライン投票率は集計していません。

## 確認ポイント

ランダム／今日の10問、全問押す／全問押さない／混合回答、連打、途中終了、再挑戦、再読み込み後の前回結果、共有キャンセルとコピーを確認してください。スマホ実機での共有動作は別途確認が必要です。
